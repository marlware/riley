# Riley
Riley is a homelab media platform backing custom Roku and Android TV clients.

<img src="/riley-logo.png" alt="Riley logo" width="150">

## Tech stack

Riley is a self-hosted connected-TV streaming platform.

- clients
  - Roku (BrightScript/SceneGraph)
  - Android TV (Kotlin/Media3) clients backed by a homelab media platform
- will implement
  - HLS transcoding
  - content discovery
  - playback-state synchronization
  - thumbnail pipelines
  - quality-of-experience telemetry

for a multi-device family video library.
